# 系统配置

配置分为三层：

1. **环境变量**：部署时注入，适合数据库、Redis、日志目录、JWT 密钥等基础设施参数。
2. **`application.properties`**：后端默认配置，环境变量可以覆盖其中同名占位符。
3. **管理界面「系统配置」**：运行期业务参数，保存在数据库中，修改后即时或重启后生效。

> 临时验证配置时优先使用环境变量覆盖，不要直接修改 `.env` 或 `application.properties`。

## 后端环境变量

配置文件：`backend/src/main/resources/application.properties`

| 变量              | 默认值            | 说明                                                               |
| ----------------- | ----------------- | ------------------------------------------------------------------ |
| `DB_HOST`         | `localhost`       | PostgreSQL 地址                                                    |
| `DB_PORT`         | `5432`            | PostgreSQL 端口                                                    |
| `DB_NAME`         | `addax_admin`     | 数据库名                                                           |
| `DB_USERNAME`     | `addax_admin`     | 数据库用户                                                         |
| `DB_PASSWORD`     | `addax_admin@123` | 数据库密码                                                         |
| `REDIS_HOST`      | `localhost`       | Redis 地址                                                         |
| `REDIS_PORT`      | `6379`            | Redis 端口                                                         |
| `REDIS_PASSWORD`  | 空                | Redis 密码                                                         |
| `REDIS_DB`        | `0`               | Redis 数据库编号                                                   |
| `SERVER_PORT`     | `50601`           | 后端监听端口                                                       |
| `LOG_DIR`         | `./logs`          | 日志目录                                                           |
| `WEIGHT`          | `1.0`             | 节点并发权重，映射到 `node.concurrency.weight`，取值 `0.0` - `1.0` |
| `WECOM_ROBOT_KEY` | 空                | 企业微信机器人 Key，多个用逗号分隔                                 |
| `JWT_SECRET`      | 内置默认值        | JWT 签名密钥，生产环境必须覆盖                                     |

### JWT 密钥

生产环境必须设置独立的 `JWT_SECRET`，否则所有环境共用默认密钥：

```bash
export JWT_SECRET="$(openssl rand -hex 32)"
```

修改密钥后，已有登录令牌会全部失效，需要重新登录。

### 节点权重

`WEIGHT` 会乘以全局和源级并发上限，用于让性能不同的节点承担不同比例的负载：

- `1.0`：不缩减
- `0.5`：承担约一半并发
- `0.0`：压到最小并发；当前实现至少保留 1 个 slot

多节点部署时，每个节点使用不同的 `WEIGHT` 即可实现加权调度。

## 前端环境变量

前端构建或开发时读取：

| 变量                | 示例                     | 说明                                          |
| ------------------- | ------------------------ | --------------------------------------------- |
| `VITE_API_BASE_URL` | `/api`                   | 前端请求的 API 前缀，默认通过 Vite/Nginx 代理 |
| `VITE_API_HOST`     | `http://localhost:50601` | 开发服务器代理的后端地址                      |

开发模式示例：

```bash
cd frontend
VITE_API_HOST=http://localhost:50601 yarn dev
```

生产镜像中，Nginx 已把 `/api` 反向代理到同容器内的后端，通常不需要额外设置。

## 管理界面系统配置

登录后进入「系统配置」，修改后点击保存。部分参数需要重启后端节点。

### 运行基础

| 配置项             | 示例             | 说明                                                            |
| ------------------ | ---------------- | --------------------------------------------------------------- |
| Addax 程序目录     | `/opt/app/addax` | 调度进程调用 `<目录>/bin/addax.sh` 并读取 `<目录>/log/`         |
| HDFS 目录前缀      | `/ods`           | 目标 HDFS 路径前缀                                              |
| 切日时间           | `16:30`          | 切日之前启动的任务仍计入上一业务日                              |
| 默认 HDFS 存储格式 | `parquet`        | 新建采集表时的默认值，可选 `orc`、`parquet`、`avro`、`textfile` |
| 默认压缩格式       | `snappy`         | 可选 `lz4`、`snappy`、`gzip`、`zstd`、`zlib`                    |

Addax 程序目录必须是后端进程所在文件系统内的路径。Docker 部署时要在 `app` 容器内可见，不能指向另一个容器。

### 执行并发与队列

| 配置项       | 示例  | 说明                                                      |
| ------------ | ----- | --------------------------------------------------------- |
| 节点最大并发 | `30`  | 集群总并发约为该值 × 在线节点数，修改后需重启所有后端节点 |
| 采集队列长度 | `100` | 排队超过该长度时，新任务等待下一轮调度                    |

### HiveServer2 连接

用于建表、表结构比对和结果校验：

| 配置项        | 示例                              |
| ------------- | --------------------------------- |
| JDBC 连接地址 | `jdbc:hive2://nn01:10000`         |
| 用户名        | `hive`                            |
| 密码          | 按实际环境                        |
| 驱动类名      | `org.apache.hive.jdbc.HiveDriver` |
| 驱动路径      | `/opt/app/lib/hive-jdbc.jar`      |

修改连接串后建议先点击“测试连接”。

### 作业模板

系统配置中维护三类 Addax 作业模板：

- 采集主模板 `R2H`
- RDBMS 读取模板 `rR`
- HDFS 写入模板 `wH`

模板由平台在创建或更新采集任务时渲染。除非明确了解模板变量含义，否则不要修改。模板编辑器中可以看到当前 JSON 内容，保存前请先备份。
