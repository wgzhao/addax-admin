# 采集源与目标端

## 采集源

采集源描述“从哪里读数据”，同时决定调度时间、调度日历和源级并发上限。

### 基本字段

| 字段          | 说明                                                          |
| ------------- | ------------------------------------------------------------- |
| 采集名称      | 业务名称，也是界面中的主要标识                                |
| 连接类型      | `关系型数据库 (JDBC)`、`MongoDB` 或 `Elasticsearch`，保存后不可切换 |
| 采集时间      | 默认触发时间，格式 `HH:mm` 或 `HH:mm:ss`；留空使用系统默认值  |
| 采集日历      | `自然日`、`工作日（含调休）`、`交易日`                        |
| 最大并发数    | 该采集源同时运行的任务数上限；留空使用系统默认值              |
| 启用调度      | 关闭后该源下所有采集定义不参与自动调度                        |
| JDBC 连接地址 | RDBMS 源的连接串；MongoDB/Elasticsearch 源不显示此字段        |
| 用户名 / 密码 | 源端凭据；MongoDB/Elasticsearch 必须同时填写或同时留空        |
| 备注          | 用途、负责人或维护注意事项                                    |

### MongoDB 采集源

连接类型选择 `MongoDB` 后，界面会隐藏 JDBC 地址，改为填写：

| 字段                | 说明                                                                 |
| ------------------- | -------------------------------------------------------------------- |
| MongoDB 地址        | 一个或多个 `host:port`，逗号分隔；不支持 `mongodb+srv://`            |
| 数据库              | 默认数据库；未在采集表上另行选择源库时使用                           |
| 认证库 authDb       | 账号所在的认证库，常见为 `admin`；界面默认 `admin`                   |
| 高级选项 (JSON)     | 可选，例如 `{"tls":"true","replicaSet":"rs0"}`                       |
| 用户名 / 密码       | 无认证时都留空；有认证时两者必须同时填写                             |

一个 MongoDB 采集源可以接入多个数据库：这里的“数据库”只是默认库，批量新增采集表时还可以选择实际源数据库，因此同一个采集源下可以分别接入不同数据库的集合。数据库和集合的采集细节见 [MongoDB 采集](10-mongodb.md)。

### Elasticsearch 采集源

连接类型选择 `Elasticsearch` 后，界面会隐藏 JDBC 地址，改为填写：

| 字段                | 说明                                                                 |
| ------------------- | -------------------------------------------------------------------- |
| Elasticsearch 地址  | 一个或多个 `http(s)://host:port`，逗号分隔；管理端按顺序尝试，采集任务使用第一个 |
| 高级选项 (JSON)     | 可选，例如 `{"insecureSkipVerify":"true","scroll":"3m"}`             |
| 用户名 / 密码       | Basic Auth 凭据；无认证时都留空，有认证时两者必须同时填写             |

Elasticsearch 没有数据库概念，管理端用固定命名空间 `indices` 承载全部索引和别名。索引、别名、字段映射与增量细节见 [Elasticsearch 采集](11-elasticsearch.md)。

### 连接测试

保存前点击“测试连接”。测试使用当前表单值，不会在列表中显示密码。

### 源停用的影响

停用采集源只会关闭自动调度：

- 该源下的采集表仍可查看和编辑。
- 可以手动发起采集。
- 历史统计、流水和日志不受影响。

需要恢复调度时重新启用采集源即可。源停用不等同于退役。

### 目标库由采集路由决定

目标库是采集路由的一部分，由用户在批量创建或表详情中显式填写，系统不会根据采集源自动推导
`ods` 之类的库名。批量创建时，如果该采集源在所选目标端上已有采集定义，向导会把最近
使用的目标库作为建议值；用户仍可修改。同一采集源可以写入不同目标库，也可以写入不同目标端。

## 目标端

目标端描述“写到哪里”，由目标端类型、Writer 模板键和连接信息组成。

### 目标端类型

当前界面支持：

| 目标端类型   | Writer 模板键 | 说明                              |
| ------------ | ------------- | --------------------------------- |
| `HDFS`       | `wH`          | Hive/HDFS，按分区写入，默认目标端 |
| `MYSQL`      | `wR`          | MySQL                             |
| `POSTGRESQL` | `wR`          | PostgreSQL                        |
| `SQLSERVER`  | `wR`          | SQL Server                        |

MongoDB 和 Elasticsearch 目前只作为采集源，不作为目标端；它们采集到的数据写入上述目标端。

目标端类型决定表详情和批量创建表单显示哪些专属属性：

- Hive/HDFS：分区绑定、分区创建方式、存储格式、压缩格式
- 关系型数据库：快照业务日期列、是否按源端主键创建主键

### 基本字段

| 字段              | 说明                                                    |
| ----------------- | ------------------------------------------------------- |
| 目标端名称 / 编码 | 业务标识                                                |
| 目标端类型        | `HDFS`、`MYSQL`、`POSTGRESQL`、`SQLSERVER`              |
| Writer 模板键     | 从下拉框选择，决定使用哪个 writer 插件模板              |
| 连接信息          | 目标端 JDBC 地址、用户名、密码                          |
| HDFS / Hive 设置  | 仅 `wH` 目标端：`defaultFS`、HDFS 前缀、`hdfsSitePath`、Kerberos、存储/压缩格式 |
| 启用              | 关闭后不能用于新建采集表                                |
| 设为默认目标端    | 批量创建时默认选中                                      |
| 备注              | 用途、负责人或维护注意事项                              |

Hive JDBC 驱动与关系型驱动统一放在后端节点的 `${APP_HOME}/drivers`，目标端不再配置驱动路径。该驱动
只供 addax-admin 建表与读取元数据，Addax 的 `hdfswriter` 不需要它。

Oracle、DB2、Sybase、ClickHouse、SQLite 暂未实现，保存目标端或测试连接时会直接报错，不会生成引用不存在 writer 插件的采集任务。

## 一个采集源可以配多个目标端吗

可以。目标端是独立资源，同一批采集表可以选择不同目标端；采集路由包含目标端和目标库，因此同一张源表写入不同目标端属于不同路由。
