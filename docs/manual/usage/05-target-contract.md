# 目标表结构与字段映射

批量新增采集表采用五步流程：选择采集源、选择采集表、配置目标策略、逐表预览与校验、查看创建结果。一个批次共用一套目标端配置，但每张表都会独立返回目标结构、字段映射、告警和阻断原因。

目标表结构的实现决策见 [ADR 0002](../../adr/0002-external-target-contract-and-column-mapping.md)。

## 目标表结构管理

| 模式                   | 目标表要求               | 平台行为                                                   |
| ---------------------- | ------------------------ | ---------------------------------------------------------- |
| `MANAGED`（平台管理）  | 可以不存在，也可以已存在 | 创建或演进目标表、写入字段映射并初始化采集任务             |
| `EXTERNAL`（外部管理） | 创建采集定义前必须已存在 | 只读取目标元数据并校验契约，不创建或修改目标表、字段和约束 |

外部管理模式适用于目标表由 DBA 或外部治理流程统一维护的场景。预览阶段会显示：

- 目标表实际结构
- 源字段与目标字段的映射
- 类型、非空约束、主键和分区不兼容项

目标结构不兼容或表不存在时，该表不能提交。提交时会重新读取目标元数据；如果预览后目标结构发生变化，该表的创建会被阻断并要求重新预览，其他表仍可独立完成创建。

### 如何选择模式

| 场景                             | 建议模式                            |
| -------------------------------- | ----------------------------------- |
| 目标表由平台统一创建和演进       | `MANAGED`                           |
| 目标表由 DBA 或外部治理流程创建  | `EXTERNAL`                          |
| 目标表已经存在，但字段由平台维护 | `MANAGED`，平台会读取现有结构并演进 |
| 不允许平台执行任何目标 DDL       | `EXTERNAL`                          |

## 字段映射

- 映射是稳定的、一对一 `source -> target` 契约，源字段与目标字段允许不同名。
- Reader 输出别名、Writer 列、目标 DDL、执行快照和错误提示使用同一份映射，避免字段改名后链路不一致。
- 不开放 SQL 表达式，目标仍按 ODS 贴源层处理，不在本平台内引入额外转换风险。
- 未映射的目标必填字段、重复目标字段和目标表结构漂移会形成阻断项；可安全忽略的额外字段会产生告警。
- 字段映射 Tab 默认只读，点击“编辑映射”后才能修改；取消不会保存，保存后会重新生成采集任务。

### 映射的执行链路

同一个映射会同时影响：

1. Reader 的源字段表达式和输出别名
2. Writer 的目标列顺序
3. 目标表 DDL 的列定义
4. 执行快照中记录的字段契约
5. 错误提示中的字段名称

因此，修改映射后必须重新生成采集任务。平台在保存映射时会自动完成这一步。

## 阻断项与告警

### 常见阻断项

- 目标表不存在（`EXTERNAL` 模式）
- 目标必填字段没有映射
- 多个源字段映射到同一个目标字段
- 目标字段类型与源字段不兼容
- 目标表结构在预览后发生漂移
- 主键或分区结构与目标契约冲突

### 常见告警

- 目标表存在可安全忽略的额外字段
- 目标表没有主键或唯一键，重复执行可能插入重复数据
- 快照业务日期列与主键策略组合存在风险

阻断项需要修复后才能提交；告警可以确认后继续。

## 批量预览与失败隔离

- 批量预览逐表隔离失败，允许排除阻断表后继续创建其余表。
- 最终确认前会对纳入创建的表重新执行完整校验，避免把过期预览直接落库。
- 一张表失败不会回滚同批次已成功的表。

## 被阻断时怎么处理

按阻断原因分别处理：

| 原因                    | 处理方式                                          |
| ----------------------- | ------------------------------------------------- |
| `EXTERNAL` 目标表不存在 | 先在目标端创建表，或在批量配置中改用 `MANAGED`    |
| 目标字段缺失            | 在目标端补充字段，或在字段映射中重新映射          |
| 类型不兼容              | 调整目标字段类型，或确认源端类型是否符合 ODS 约定 |
| 预览后结构漂移          | 重新执行预览，确认最新目标结构后再提交            |
| 必填字段未映射          | 在“字段比较”中点击“编辑映射”补齐                  |
| 重复目标字段            | 检查映射是否把多个源字段指向同一目标列            |
