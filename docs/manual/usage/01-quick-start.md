# 快速上手

本文用一条最短路径完成第一次采集：登录 → 配置采集源 → 配置目标端 → 批量创建采集表 → 发起采集。

## 1. 登录并修改密码

打开管理界面，使用默认账号登录：

- 用户名：`admin`
- 密码：`admin123`

首次登录后，从右上角用户菜单进入「修改密码」，不要继续使用默认密码。

## 2. 确认运行配置

进入「系统配置」，至少确认：

- **Addax 程序目录**：后端进程可以访问的 Addax 安装路径，例如 `/opt/app/addax`
- **HDFS 目录前缀**：如果使用 Hive/HDFS 目标端
- **默认存储格式 / 压缩格式**：新建采集表时的默认值
- **HiveServer2 连接**：如果使用 Hive 目标端，点击“测试连接”确认可用

## 3. 配置采集源

进入「采集源管理」，点击新增，填写：

| 字段          | 说明                                              |
| ------------- | ------------------------------------------------- |
| 采集编号      | 两位大写字母，例如 `CR`，保存后不可修改           |
| 采集名称      | 业务名称，例如“客户关系中心”                      |
| 采集时间      | `HH:mm` 或 `HH:mm:ss`；留空时使用系统默认调度时间 |
| 采集日历      | 自然日、工作日（含调休）或交易日                  |
| 最大并发数    | 该采集源的最大并行任务数；留空使用系统默认值      |
| JDBC 连接地址 | 源端数据库连接串                                  |
| 用户名 / 密码 | 源端数据库凭据                                    |
| 启用调度      | 关闭后不参与自动调度，历史配置保留                |

填写连接信息后先点击“测试连接”，保存前确认连接成功。

## 4. 配置目标端

进入「目标端管理」，点击新增，填写：

- **目标端类型**：Hive/HDFS 或关系型数据库
- **Writer 模板键**：`wH`（Hive/HDFS）或 `wR`（关系型数据库）
- **JDBC 连接信息**：目标端连接地址、用户名、密码
- **启用**：是否参与使用
- **设为默认目标端**：批量创建时默认选中

同样建议先测试连接。目标端能力与限制见 [目标端能力与表属性](06-target-engines.md)。

## 5. 批量创建采集表

进入「采集表配置」，点击「新增采集表」，按五步完成：

1. **选择采集路由**：选择采集源和源库。
2. **选择采集表**：勾选要接入的表；已退役的采集表不能重复新增，应在“已退役”入口恢复。
3. **配置目标策略**：
   - 目标表结构管理：`平台创建并维护` 或 `目标表已存在，仅校验`
   - 目标端与目标库
   - 目标表名模板：支持 `${table}`（源表名）和 `${db}`（源库名）
   - Hive 目标端：配置分区绑定、分区创建方式、存储与压缩格式
   - 关系型目标端：配置快照业务日期列和是否创建主键
4. **预览与校验**：逐表查看目标结构、字段映射、阻断项和告警；排除阻断表后可以继续创建其余表。
5. **创建结果**：查看每张表的创建结果和失败原因。

详细说明见 [批量创建采集表](04-create-collections.md) 和 [目标表结构与字段映射](05-target-contract.md)。

## 6. 发起采集并验证

- 在采集表列表中点击「发起采集」，或勾选多张表后点击「批量采集」。
- 进入「采集任务管理」查看排队中、运行中和最近完成的任务。
- 打开采集表详情，查看：
  - **采集日志**：本次执行日志
  - **采集结果**：读写统计
  - **执行快照**：执行时冻结的配置、字段映射和上下文

常见状态：

| 状态 | 含义           |
| ---- | -------------- |
| `N`  | 未采集         |
| `W`  | 等待采集       |
| `R`  | 正在采集       |
| `Y`  | 已采集         |
| `E`  | 采集错误       |
| `X`  | 不采集（停采） |
| `U`  | 等待更新       |
