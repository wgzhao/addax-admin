# 动态表名

动态表名用于处理按日期切分的源表，例如日表、月表。在源表名中写入 `${变量}`，平台会在任务生成和资源刷新时替换成实际日期。

## 基本语法

```text
t_order_${biz_date_short}
```

如果任务业务日是 2026-01-27，读者实际读取：

```text
t_order_20260127
```

变量使用 `${name}` 形式。源表名字段中出现 `${` 时，平台会执行替换。

> 目标表名模板是另一套占位符，只支持 `${table}`（源表名）和 `${db}`（源库名），不要和日期变量混用。

## 业务日期与当前日期

| 前缀     | 含义           | 典型用途                         |
| -------- | -------------- | -------------------------------- |
| `biz_*`  | 跟随任务业务日 | 日表、月表、按业务日期分区的源表 |
| `curr_*` | 实际运行时间   | 运行时间戳、补数时的实际执行时间 |

跨日重试或补数时，业务日期可能不等于实际运行日期：

- `biz_*` 仍然是任务业务日。
- `curr_*` 是真实运行时间。

选择变量前先确认源表是按业务日期还是按实际运行日期切分。

## 变量目录

### 业务日期

| 变量                 | 含义                     | 格式         | 示例         |
| -------------------- | ------------------------ | ------------ | ------------ |
| `${biz_date_short}`  | 任务业务日期，紧凑格式   | `yyyyMMdd`   | `20260127`   |
| `${biz_date_dash}`   | 任务业务日期，短横线格式 | `yyyy-MM-dd` | `2026-01-27` |
| `${biz_year}`        | 业务年份                 | `yyyy`       | `2026`       |
| `${biz_month}`       | 业务月份，两位数字       | `MM`         | `01`         |
| `${biz_short_month}` | 业务月份，不补零         | `M`          | `1`          |
| `${biz_day}`         | 业务日，两位数字         | `dd`         | `27`         |
| `${biz_short_day}`   | 业务日，不补零           | `d`          | `27`         |
| `${biz_ym}`          | 业务年月                 | `yyyyMM`     | `202601`     |
| `${biz_short_ym}`    | 业务年月，月份不补零     | `yyyyM`      | `20261`      |

### 业务日期时间

| 变量                      | 含义                              | 格式                  | 示例                  |
| ------------------------- | --------------------------------- | --------------------- | --------------------- |
| `${biz_datetime_short}`   | 业务日期与当前时分秒，紧凑格式    | `yyyyMMddHHmmss`      | `20260127140530`      |
| `${biz_datetime_dash}`    | 业务日期与当前时分秒，短横线格式  | `yyyy-MM-dd HH:mm:ss` | `2026-01-27 14:05:30` |
| `${biz_datetime_0_dash}`  | 业务日期当天 00:00:00，短横线格式 | `yyyy-MM-dd 00:00:00` | `2026-01-27 00:00:00` |
| `${biz_datetime_0_short}` | 业务日期当天 00:00:00，紧凑格式   | `yyyyMMdd000000`      | `20260127000000`      |

### 当前日期

| 变量                 | 含义                     | 格式         | 示例           |
| -------------------- | ------------------------ | ------------ | -------------- |
| `${curr_date_short}` | 实际运行日期，紧凑格式   | `yyyyMMdd`   | 以实际运行为准 |
| `${curr_date_dash}`  | 实际运行日期，短横线格式 | `yyyy-MM-dd` | 以实际运行为准 |

### 当前日期时间

| 变量                       | 含义                                | 格式                  | 示例           |
| -------------------------- | ----------------------------------- | --------------------- | -------------- |
| `${curr_datetime_short}`   | 实际运行日期时间，紧凑格式          | `yyyyMMddHHmmss`      | 以实际运行为准 |
| `${curr_datetime_dash}`    | 实际运行日期时间，短横线格式        | `yyyy-MM-dd HH:mm:ss` | 以实际运行为准 |
| `${curr_datetime_0_dash}`  | 实际运行日当天 00:00:00，短横线格式 | `yyyy-MM-dd 00:00:00` | 以实际运行为准 |
| `${curr_datetime_0_short}` | 实际运行日当天 00:00:00，紧凑格式   | `yyyyMMdd000000`      | 以实际运行为准 |

表详情中的“动态命名”帮助弹窗提供同样的变量目录，并支持搜索和复制。

## 示例

### 日表

源表名：

```text
t_order_${biz_date_short}
```

实际读取：

```text
t_order_20260127
```

### 月表

源表名：

```text
t_order_${biz_ym}
```

实际读取：

```text
t_order_202601
```

### 带运行时间戳的临时表

源表名：

```text
t_snapshot_${curr_datetime_short}
```

实际读取：

```text
t_snapshot_20260127140530
```

## 注意事项

- 动态表名只改变读者实际读取的源表，不改变目标表命名。
- 变量名区分大小写，必须与目录一致。
- 如果业务日期或实际运行日期不符合预期，先检查系统配置中的“切日时间”。
- 跨日重试或补数时，`biz_*` 和 `curr_*` 可能落在不同日期，务必确认源表实际按哪个日期切分。
- 动态表名配合过滤条件时，可以在过滤表达式中继续使用同一批日期变量，见 [增量与过滤](08-filtering.md)。
