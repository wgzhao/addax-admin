# 核心概念

Addax Admin 的领域术语以仓库根目录的 [CONTEXT.md](../../../CONTEXT.md) 为准。理解下面几组区别，可以避免大多数配置和生命周期问题。

## 采集路由

**采集路由**是一条采集定义的身份，由以下五项共同确定：

1. 采集源
2. 源库/命名空间
3. 源表
4. 目标端
5. 目标库

同一采集路由在生命周期内只允许存在一条采集定义。即使定义被退役，路由仍然被占用；重新采集时应恢复原定义，而不是为同一路由新建第二条。

## 采集定义

**采集定义**描述一张采集表当前如何从源端采集到目标端，是可变的配置，包括：

- 源表与目标表
- 目标表结构模式与字段映射
- 过滤条件、动态表名
- 写入模式、主键与分区策略
- 调度时间、重试次数、最大运行时长
- Reader/Writer 插件配置

采集定义可以修改，但每次实际执行都会冻结一份执行快照。

## 采集执行与执行快照

**采集执行**是一次实际启动的采集尝试，拥有独立的开始时间、结束时间、结果和配置快照。

**执行快照**在采集执行开始时冻结当时的采集定义、字段映射和必要上下文。之后修改配置不会改变历史快照，因此排查历史问题时应查看快照，而不是查看当前配置。

## 生命周期状态

| 状态             | 含义                                             | 是否参与自动调度 |
| ---------------- | ------------------------------------------------ | ---------------- |
| 使用中           | 采集定义有效，表级和源级都未停用                 | 是               |
| 停采             | 采集定义仍然有效，但表级标记为不采集（状态 `X`） | 否               |
| 源停用           | 采集源保留配置但不参与自动调度                   | 否               |
| 暂停中的采集定义 | 未退役，但因停采或源停用而不参与自动调度         | 否               |
| 已退役           | 定义停止参与展示和调度，但历史事实保留           | 否               |

### 停采、源停用与退役的区别

- **停采**：只影响当前采集表，采集定义仍可编辑，可以恢复为正常调度。
- **源停用**：影响该采集源下的所有采集定义；这些表仍可查看、编辑和手动执行。
- **退役**：从日常列表和自动调度中移除，保留配置历史、统计、流水和日志。退役不是删除。
- **恢复**：清除退役状态。恢复不会改变表级停采或源停用状态，因此恢复后的定义仍可能处于暂停状态。

## 目标表结构模式

**目标表结构模式**决定目标表和字段由谁维护：

| 模式                   | 含义                                                                           |
| ---------------------- | ------------------------------------------------------------------------------ |
| `MANAGED`（平台管理）  | 目标表可以不存在；平台负责创建或演进目标表、写入字段映射并初始化采集任务       |
| `EXTERNAL`（外部管理） | 目标表必须已存在；平台只读取实时元数据并校验目标契约，不创建或修改目标表和字段 |

## 字段映射

**字段映射**是采集定义中源字段与目标字段之间稳定的一对一契约：

- 源字段与目标字段允许不同名。
- Reader 输出别名、Writer 列、目标 DDL、执行快照和错误提示使用同一份映射。
- 不开放 SQL 表达式，目标仍按 ODS 贴源层处理。
- 未映射的目标必填字段、重复目标字段和目标表结构漂移会形成阻断项。

## 目标契约

**目标契约**是采集定义对目标表存在性、字段、类型、约束和分区结构的可执行要求。`EXTERNAL` 模式下，目标契约在预览和提交时都会重新校验；目标结构漂移会阻断该表，但不会影响同批次其他表。

## 分区绑定

**分区绑定**描述目标分区键与运行期取值之间的关系：

- 业务日期：按任务业务日取值
- 固定值：每次写入同一个值

一个 Hive 目标表最多配置一个业务日期分区，其余分区键使用固定值。分区创建可以由平台负责（`PLATFORM`），也可以由外部负责并在运行前校验（`EXTERNAL`）。

## 历史事实

采集执行产生的统计、流水和日志属于**历史事实**，生命周期独立于采集定义。即使采集定义退役，历史统计、流水和日志仍然可以查询。
