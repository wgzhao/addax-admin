# 采集源与采集表状态矩阵

此矩阵是采集表管理 E2E 的公开行为契约。测试 seam 为采集表管理页面和 `/api/v1/tables` 接口。

## 行为定义

- 当前定义 `CURRENT`：所有未退役采集表，包括停采表（`X`）和源停用表。
- 暂停中 `DORMANT`：未退役，且表状态为 `X` 或所属源停用。
- 已退役 `RETIRED`：只包含 `retired_at` 非空的采集表。
- 全部 `ALL`：所有采集表。
- 编辑：未退役可编辑；已退役必须先恢复。
- 恢复：只清除退役状态，不改变表状态或源状态。

## 操作边界

| 操作 | 前置状态 | 期望 |
|---|---|---|
| 默认列表 | 任意 | 等同 `CURRENT`，包含停采和停用源表 |
| 旧参数 `lifecycle=ACTIVE` | 任意 | 兼容为 `CURRENT` |
| 源筛选 | 任意 | 启用源和停用源都能筛出各自全部当前状态 |
| 状态筛选 `X` | 当前定义 | 同时包含启用源和停用源的 `X` 表 |
| 退役 | 当前定义、无活动任务 | 成功；重复退役仍成功 |
| 退役 | 当前定义、存在 pending/running 任务 | 返回 400，状态不变 |
| 恢复 | 已退役、无活动任务 | 成功；不要求源或目标端启用 |
| 恢复 | 当前定义 | 返回 400 |
| 恢复 | 已退役、存在 pending/running 任务 | 返回 409，状态不变 |
